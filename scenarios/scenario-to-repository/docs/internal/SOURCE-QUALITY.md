# Source quality measurement

The source-ramp quality floor is based on comparable export attempts, not
operator adoption claims. The required sensors are closure completeness,
reproducibility, policy escapes, clean-build status, stale evidence, and
failed exports. A failed or adverse case remains in the denominator.

The initial golden corpus should include: equal-input deterministic builds,
secret-like README content, escaping links, private plan artifacts, unknown
asset licensing, case collisions, duplicate archive entries, oversized
entries, missing runtime requirements, and destination drift. A repair is
accepted only when the adverse case still fails closed and the corresponding
positive fixture remains passing.

No production adoption, publication rate, or long-term learning efficacy is
claimed until comparable operator-owned attempts exist.

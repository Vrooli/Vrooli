# Aquila hero mockups

These are standalone, dependency-free HTML concepts for the configurable landing-page redesign. Open [`index.html`](./index.html) first, then choose a direction.

| File | Direction |
| --- | --- |
| [`aquila-hero-01-command-at-rest.html`](./aquila-hero-01-command-at-rest.html) | Aquila-only, dark operational workspace with layered UI panels |
| [`aquila-hero-02-field-notes.html`](./aquila-hero-02-field-notes.html) | Aquila-only, light editorial workspace artifact |
| [`bundle-hero-01-constellation.html`](./bundle-hero-01-constellation.html) | Bundle, dark product constellation with staged capabilities |
| [`bundle-hero-02-one-system.html`](./bundle-hero-02-one-system.html) | Bundle, light operating-model/process map |

The concepts borrow from Backdrop Studio’s surface-specific approach: an explicit copy-safe region, restrained treatment, layered artifacts, and labels that describe the target surface. They do not make production changes or remove Browser Automation Studio content. BAS is intentionally represented as a clearly staged “Coming next” capability in the bundle concepts; its existing copy and assets remain migration inputs for the future disabled app profile.

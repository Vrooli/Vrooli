# VPS setup — superseded

> **Superseded 2026-11-24.** Do not use this retired manual setup guide. Compute Manager owns
> provider setup and adoption. Scenario-to-Cloud consumes the admitted Compute Manager target, and
> Deployment Manager owns the deployment pipeline.

For an existing VPS, open **Compute Manager → Adopt**, enter the host and declared cost facts, then
continue through the secure Onboarding step when the required first-touch approval is available.
Enter any one-time credential only in that write-only Onboarding field. Do not send it in chat or
save it in a document.

For provider-managed compute, use that provider's console only for the provider-owned account and
server actions. Continue setup, verification and deployment in the product flows. No live VPS
adoption or deployment is claimed by this guide.

See the [Scenario-to-Cloud quick start](../QUICKSTART.md) for the current product ownership and
status.

# Workflow Asset Layout Alias

This page is retained for old links. The active BAS asset layout is owned by
`workflow-health`, and Test Genie consumes it only through the delegated
[`workflow` phase](../workflow/README.md).

Use the workflow-health documentation for current guidance:

- `scenarios/workflow-health/docs/concepts/DATA.md`
- `scenarios/workflow-health/docs/concepts/FLOWS.md`

The legacy path name `playbooks` may still appear in API fields, seed commands,
and artifact paths for compatibility. New phase configuration and operator docs
should use `workflow`.

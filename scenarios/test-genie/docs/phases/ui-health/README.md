# Retired Phase Key: `ui-health`

The `ui-health` Test Genie phase key was retired when UI Health became the owner of the canonical `experience` phase. Use the [Experience phase guide](../experience/README.md) for the single served-UI verdict and the separately scoped `experience-contract` phase.

Update old invocations from `--phases ui-health` / `--skip ui-health` to `--phases experience` / `--skip experience`. `ui-health validate scenario <scenario>` remains the provider's direct full validation command.

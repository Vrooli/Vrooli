# Glossary

| Term | Meaning |
|---|---|
| Analyzer | A language graph provider such as `go-code-graph` or `typescript-code-graph`. |
| Code target | Caller-supplied bounded input: path, scenario, module, or project. |
| Evidence | Status plus source location, symbol, provider, confidence, and message. |
| Fact family | Named subset of facts requested by callers. |
| Parse unit | Concrete module/project root sent to an analyzer. |
| Proof | Higher-level evidence synthesized from generic facts. |
| Surface | Scenario-facing area such as API, CLI, UI, sidecar, endpoint, or command. |

# Fact Families

| Family | Meaning |
|---|---|
| `surfaces` | Scenario API/CLI/UI/sidecar metadata and status. |
| `parse_units` | Go modules, TS projects, explicit configs, and unsupported units. |
| `imports` | Import specs/bindings from provider graphs. |
| `symbols` | Declarations and public symbols. |
| `references` | Resolved symbol references. |
| `calls` | Call expressions and argument summaries. |
| `proto_adoption` | Generated proto artifact adoption evidence. |
| `endpoint_proofs` | Static endpoint implementation evidence. |
| `cli_proofs` | Planned CLI implementation evidence. |
| `ui_widget_proofs` | Planned UI widget evidence. |
| `all` | All supported families for the target. |

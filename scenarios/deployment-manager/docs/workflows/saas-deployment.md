# Hosted deployment

Hosted deployment uses one tracked Deployment Manager operation. The phone
flow presents setup decisions, provider website steps, progress, health, and
recovery. It does not ask the operator to run deployment or host-management
commands.

This path is under development. The current system does not claim a verified
staging or production deployment through this operation. Follow the
[Deployment Hub](../../../../docs/deployment/README.md) for current support and
the [Deployment Manager cloud deployment guide](../DEPLOYMENT-GUIDE.md) for the
operator boundary.

# Experience Audit

## Positive Flows

1. Task board makes queue state and progress visible.
2. Settings modal centralizes execution and steering controls.

## Friction

1. Operator context switching between logs, settings, and task details remains high under failure scenarios.
2. Dense task cards can hide key blockers without opening details.

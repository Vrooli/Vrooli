# BAS Playbooks

This directory holds Business Acceptance Scenario playbooks for Fall Foliage Explorer.

## Structure

- `cases/` is reserved for target-specific acceptance cases grouped by PRD operational target.
- `flows/` is reserved for cross-target user journeys such as foliage discovery, reporting, trip planning, and export.
- `registry.json` is generated by `test-genie registry build`.

## Current Status

No BAS playbook cases are authored yet. API, CLI, and UI smoke coverage is currently represented through requirements modules and Go tests. Future workflow work should add cases under the matching target folder and rebuild the registry.

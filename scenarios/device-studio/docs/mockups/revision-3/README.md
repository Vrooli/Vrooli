# Physical still editor extension

This paired concept extends the approved Light-table shot workspace to the physical still path. It retains the same visual system and separates the sequential 430px mobile flow from the desktop stage and inspector.

The stage is source-only until an actual render exists. Candidate components are labeled as candidates, backend choice is explicit, and no 3D preview or qualification is implied.

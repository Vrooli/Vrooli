# Decisions — Device Studio

## Purpose Of This Document

Preserve accepted choices and their rationale. Historical research snapshots remain evidence; this document and PRD express current intent.

## Decision Log

| Decision | Accepted choice | Rationale / consequence |
|---|---|---|
| Scenario boundary | Device-specific scenes/models/presentation/motion/shots and creation/qualification | Stable reusable capability; capture, film editing, commerce, generic publication and host tooling stay at existing owners |
| First complete release | Eight representative groups; actual phone spin and laptop hinge | A photographic milestone is useful but cannot satisfy requested physical motion/breadth |
| Editing | Guided builder plus advanced camera/light/placement/calibration/keyframes | Power without recreating a full mesh/shader editor |
| Output |1080p 24/30 fps SDR landscape/portrait; adequate high-res stills | Qualify quality/performance before 4K/HDR expansion |
| Rendering | Configuration-dependent photographic and full 3D | Fixed plates offer high-quality efficient eligible shots; geometry/motion requires native scene work |
| Deployment | Current-host proof first, cross-platform downloadable desktop design from start | Avoid checkout/fleet/OS assumptions; each platform claims only native evidence |
| Funding | Explicit local/BYOK/Vrooli credit route | Reuse normal monetization; no automatic paid fallback or private wallet |
| Privacy | Per-project opt-in for external actual app media | Applies to generation, critique, derived media and remote agent vision |
| Autonomy | Budgeted search/import/build/compare/refine, review before library release | Keep useful automation while preserving scope/rights/craft approval |
| AI disclosure | Visible before AI calls or agent initiation; bounded nested activity visible | No surprise generation, charges or agents in routine editing |
| Model sourcing | Zero purchase, high-quality free source where available; reference-based accurate/generic fallback | Exact permissions and dimensions matter more than a free-download label |
| Preservation | Original 2 GB research stays in place, with hash baseline and portable text snapshots | Historical rejected/accepted outputs and source provenance remain recoverable |
| Historical foundation scope | Scaffold/docs/PRD/requirements/experience only, now complete | Historical evidence stays distinct from the newly authorized implementation |

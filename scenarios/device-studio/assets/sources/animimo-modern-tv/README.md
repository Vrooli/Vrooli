This directory retains the exact original GLB downloaded anonymously from Animimo Studios' creator page. The source page and its representative preview are retained in `docs/internal/goal/evidence/E4/family-candidates-20261021/`.

The atlas includes a photographed TV front and rear; it includes visible wordmark-like labels (“NEXUS” and “LONEY”).

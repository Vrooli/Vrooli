# Laptop derive16 candidate asset

`laptop-neutral-rig.glb` starts from retained derive16 (`c3eef69a…e51651`) and applies two deterministic display-only adaptations. It removes `emissiveFactor`, `emissiveTexture`, and `KHR_materials_emissive_strength` from the neutral display slot because the project-owned screen raster replaces that slot. It also copies the screen primitive's exclusive UV0 accessor and affine-normalizes its measured inset chart `[0.0065305233,0.9935087562]` to `[0,1]`. The original GLB BIN payload remains the exact prefix; positions, normals, indices, other node transforms, and non-screen material JSON stay unchanged. The reproducible script, input bytes, and source/derived hashes are in the E3 physical-candidate evidence.

The creator attribution is Jack Baeten, MacBook Pro M3 16 inch 2024, CC BY 4.0; attribution is required. This is a Vrooli adaptation, not manufacturer CAD, endorsement, or physical measurement.

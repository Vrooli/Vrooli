# Embedded reviewed starters

Each reviewed starter is an explicit local install choice. Its compact certificate contains the exact candidate, source bundle revisions, scene, motion, preset, review and render receipt from a retained native qualification package. The separate PNG and pinned embedded source bytes reconstruct that package for the existing verifier/importer. No render job or provider call is created during install.

The installer allowlists starter IDs and source paths, pins the compact certificate and inner `package_sha256`, and checks the output and every source artifact byte against the retained references before import. The inner package digest covers canonical package contents; it differs from an external JSON file's SHA-256. Digests detect changed bytes and bind records; they do not constitute cryptographic reviewer signatures.

Every imported review remains limited to its recorded static setup, display, dimension state, support, candidate, scene, motion, preset, source revisions and native output. It does not qualify other poses, motion, measured dimensions, device identity or unrestricted use. Source Library rights remain unchanged. Per-starter `README.md` files list exact references and attribution. The Jack Baeten laptop source requires CC BY 4.0 attribution.

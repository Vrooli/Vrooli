# Starter phone-study table geometry

This package contains the CPU-exported 8-node table/cup GLB and four original
CC0 Travertine001 maps. `asset-manifest.json` pins each shipped file by size and
SHA-256, records the emitted node/material bindings, and describes the top
support frame in `TableTop` local coordinates. Its world top is about 0.75 m;
the support frame's local vertical offset is about 0.017 m.

This is a portable starter package, not a Library promotion. It has no Library
bundle, review, or `ArtifactRef`. The asset contains the table slab, four legs,
cup, handle, and tea cue only. The study back wall, luminous window panel and
frame are absent; those affect indirect light and are needed for fuller scene
reproduction. The table-only candidate is not claimed to reproduce the complete
phone-study image.

The geometry is Vrooli-authored and the texture rights are stated in
[`LICENSE.md`](LICENSE.md). The separately retained source and native export
receipt are linked by exact hashes in `asset-manifest.json`.

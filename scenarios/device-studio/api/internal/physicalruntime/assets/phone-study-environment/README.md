# Phone-study environment geometry starter

This package contains the parent-operated CPU export of the static table/cup scene plus a warm wall, luminous window panel, and four window-frame pieces. The GLB has no embedded or external images, camera, lights, phone, or animation. Exact node and material inventory, support frame, and source bindings are in `asset-manifest.json` and `environment-inventory.json`.

The sibling [`phone-table`](../phone-table/README.md) package carries the Travertine001 maps. This environment GLB does not bind those images; a consumer must apply a typed material binding. The geometry is a Vrooli-authored scene interpretation, not measured room or furniture CAD. This is an unreviewed starter candidate, not Library promotion.

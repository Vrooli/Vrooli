# Evidence Pack

The generated visual evidence for the image-treatment and placement work is
kept under `docs/evidence/`, grouped by plan phase. The PNGs are deliberately
opaque artifacts rather than documentation pages, so the documentation
contract does not attempt to register each image as a document.

The evidence index covers deterministic treatment goldens, guided and
synthesized lane seams, device composition, the treatment contact sheet, and
desktop/mobile placement previews. Model-backed output remains capability
gated by the configured image-tools inference backend.

# Go-To-Market — Network Manager

## Audience

Initial audience: technical homeowners and homelab operators. Secondary audience: small-office operators and Vrooli service deployments.

## Positioning

Network Manager is a local-first control center for internet health, DNS filtering, device policy, and safe optimization. The product promise is evidence-backed improvement and control, not magic speed claims.

## Launch Motion

1. Prove one real home deployment.
2. Publish before/after reports and privacy defaults.
3. Add Home Automation controls to show ecosystem value.
4. Validate small-office audit/report needs.
5. Package as a lifestyle bundle capability and later as Business Suite depth.

## Differentiators

- Agentic optimization loop with baseline/candidate/after evidence.
- Resolver policy and rollback through Vrooli.
- Home Automation integration.
- OS-agnostic adapter model with honest capability reporting.
- Local-first privacy posture.

## Validation Questions

1. Does the first personal deployment reduce friction compared with manually setting up AdGuard Home?
2. Do users trust DNS/query visibility defaults?
3. Which router platform should receive the first adapter?
4. Are small-office users willing to pay for audit reports and policy history?

## Acceptance

- The operator opens the real swarminator desktop from mobile Web Console, sees live frames, moves the pointer, and types into a focused field over the existing authenticated route.
- Viewer mode cannot submit input. Geometry changes, lease replacement, session close, lock and node revocation fence native effects. The host releases held input on lease end.
- A graphical login after restart can reacquire the approved X11 display. Restarting Bridge or the companion invalidates old leases, and the browser can reconnect without manual service setup.
- Restricted networks can use the same-origin HTTPS frame route. WebRTC remains available for low-latency routes.
- The operator signs into Studio in the controlled session using Roblox UI. The login flow keeps credentials in the operator’s control.
- Device Control owns capture and input. Bridge owns trusted dispatch and Web Console owns presentation. Installation is user-scoped and uses the documented service lifecycle.

## Current proof and open gate

The production companion serves X11 readiness on swarminator over a mode-0600
owner socket. Two consecutive native WebRTC sessions delivered live VP8 RTP
and moved the real pointer to a chosen coordinate before restoring it. The
HTTPS frame method returned a bounded JPEG from the real display, and typed
mixed case and punctuation into a disposable native field. The configured
user service regained readiness on two restarts. The browser suite exercised
Connect-JSON enum and lease encoding, viewer protection, WebRTC and HTTPS
frame/keyboard paths with software fixtures.

The previous linked-node pin did not verify the running Bridge signer. The
operator authorized replacing that public pin. The replacement matched the
active Vrooli Bridge public key. The node identity and grants stayed in place.

The deployed Web Console loaded and decoded a 1280×720 frame at a 390×844
browser viewport. The browser test exercised the real Devices navigation,
opened control, verified the private typing field, and revoked the lease.
A separate request round trip through deployed Web Console and Bridge
typed mixed-case text and punctuation into a disposable X11 field.
Live frame capture was repeated after a Bridge restart.

The first Bridge restart stalled on its connected SSE reader. The handler
now exits on the lifecycle admission signal and the agent reconnects.
A subsequent unforced restart with the node attached took about eight seconds
and the same node returned online. The pending operator smoke test is the
actual phone and the Roblox sign-in. Keep test input and screenshots away
from credential entry.

The first scenario unit run was blocked by two tests importing deleted local UI
primitives. The obsolete wrapper tests were removed. Device Control UI type
checking passed afterward. The generated protocol verification passed.

The broader API unit phase remains red. Identified failures cover desktop

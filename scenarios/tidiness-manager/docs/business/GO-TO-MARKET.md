# Go To Market

Tidiness Manager is primarily an internal capability for Vrooli agents and scenario maintainers. It can later become part of an engineering-quality bundle that helps teams discover maintainability debt before it blocks delivery.

## Users

- Agents performing refactors.
- Developers maintaining scenarios.
- Operators reviewing cleanup campaigns.

## Positioning

Tidiness Manager is not a generic linter. It is a campaign-oriented maintainability coordinator that helps prioritize structural cleanup across a scenario ecosystem.

## Deferred Commercial Work

External packaging, pricing, and enterprise workflows remain deferred until the internal capability is comprehensive-green and stable.

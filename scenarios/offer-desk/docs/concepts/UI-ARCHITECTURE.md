# Offer Desk information architecture

| Route | Surface | Desktop | Mobile |
|---|---|---|---|
| `/` | Ranked board | priority queue plus posture summary | priority-one rows before posture; bottom nav pinned in the safe area |
| `/offers` | Catalog | graph/list with status and typed relationships | stacked node cards and readable refusal messages |
| `/triggers` | Gates | trigger, fact, and evaluation tables | sequential cards with freshness beside values |
| `/proposals` | Operator decisions | proposal queue and role explanation | stacked approval cards |
| `/settings` | Theme and locale | settings form | stacked controls |

The board's first visual priority is fired triggers, followed by active offers with no actuals. Every Money Ledger figure carries source/basis and availability. Status and direction are never communicated by color alone; labels and words remain present.

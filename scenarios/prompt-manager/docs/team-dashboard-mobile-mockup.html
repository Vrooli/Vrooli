Team Dashboard — mobile interaction concept

This is an intentional mobile composition, not a desktop page squeezed into a phone.

390px mobile viewport

Mobile design decisions

  • Mission stays prominent: the editable mission is still the first meaningful surface after identity.
  • Metrics scroll horizontally: the operator gets quick status without shrinking text or creating a tall grid.
  • Work comes before configuration: mobile users see what needs attention before low-frequency settings.
  • Details collapse: evidence, authority, and coverage remain available without overwhelming the narrow view.
  • Bottom navigation is persistent: Overview, Work, People, and Activity remain reachable without a crowded header.
  • States are explicit: paused, blocked, waiting, and unknown are visible through labels and copy, not color alone.

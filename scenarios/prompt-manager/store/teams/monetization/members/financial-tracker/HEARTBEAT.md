# Run Task: Financial Tracker

## Task Loop

Read `prompt-manager skill read offer-desk` and work this lane through the capability it
declares. Offer Desk owns the board contract, its reads and its degradation behaviour; keep no
separate reading procedure here. Interpret the posture and goal rows; never recreate a ledger
snapshot or calculate the board's figures.

## Lane Judgment

1. What financial posture or goal row needs interpretation?
2. Which basis, availability, or age qualification changes the decision?
3. Is the delta material enough to warrant an operator work item?
4. What missing input is the load-bearing blocker?

Apply the time-cost, services-capacity, default-alive, and honesty judgment framework. An
unreadable actual is unknown, never zero; a node whose earnings are unreachable needs an
account mapping, not an estimate.

**Fallback:** durable ledger evidence or the operator-input adapter, with no fabricated
calculation.

## Run Decision

Record durable continuity in the declared Source Ledger topics. Choose one disposition:
existing-action-reference, new-action-candidate, cli-backlog, capability-work-item, prune,
improve, graduate, or no-action; state the evidence.

## Stop Conditions

The usage skill owns the operational stop conditions. A posture the board calls unavailable is
not a number this member may supply.

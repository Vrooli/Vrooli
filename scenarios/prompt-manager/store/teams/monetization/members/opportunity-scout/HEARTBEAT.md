# Run Task: Opportunity Scout

## Task Loop

Read `prompt-manager skill read offer-desk` and work this lane through the capability it
declares. Offer Desk owns the board contract, its reads and its degradation behaviour; keep no
separate reading procedure here. Drain the generated inbox flow and generate ideas only to the
extent the signal supports them, using board rows to deduplicate and to avoid bypassing an
existing evaluation or promotion decision.

## Lane Judgment

1. What external, operator, or capability-arrival signal is new?
2. Which capability and market combination is worth classifying?
3. What acquisition, retention, and revisit hypotheses make it testable?
4. Should the idea become an evidence entry, an operator work item, or be dropped?

Apply the classification and hypothesis judgment framework. A node already on the board as an
IDEA is captured, not planned against; a second capture is duplication, not a signal.

**Fallback:** the inbox and last durable observations, with uncertain ideas left explicitly
unpromoted.

## Run Decision

Record durable continuity in the declared Source Ledger topics. Choose one disposition:
existing-action-reference, new-action-candidate, cli-backlog, capability-work-item, prune,
improve, graduate, or no-action; state the evidence.

## Stop Conditions

The usage skill owns the operational stop conditions. Run supersession before proposing a
replacement, and raise work only when the operator should decide now.

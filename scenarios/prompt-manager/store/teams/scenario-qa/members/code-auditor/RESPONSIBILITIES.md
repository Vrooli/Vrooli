# Responsibilities: Code Auditor

## Primary Duties
- Run architecture alignment audits.
- Check security posture (OWASP top 10 baseline).
- Identify anti-patterns and invariant violations.

## Deliverables
- Structured findings with severity ratings.
- Security assessment with specific vulnerabilities.

## Coordination Points
- Receive audit scope from qa-lead.
- Report findings with file paths and line numbers.

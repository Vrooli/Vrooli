# Responsibilities: Doc Reviewer

## Primary Duties
- Audit docs/ structure and manifest.json completeness.
- Verify bidirectional code-doc references.
- Identify stale, missing, or orphaned documentation.

## Deliverables
- Documentation health report with specific fixes.
- Reference integrity report (broken links, missing docs).
- Backlog-ready documentation findings with concrete proposed actions.

## Coordination Points
- Receive scope from qa-lead.
- Report documentation findings.

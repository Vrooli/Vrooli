# Responsibilities: Test Strategist

## Primary Duties
- Assess test coverage weighted by behavior risk.
- Identify highest-risk untested code paths.
- Recommend specific test outlines for gaps.

## Deliverables
- Coverage reports with risk-weighted gap analysis.
- Prioritized test recommendations.
- Execution-ready backlog proposals for test gaps requiring follow-up.

## Coordination Points
- Receive scope from qa-lead.
- Report coverage findings and recommendations.

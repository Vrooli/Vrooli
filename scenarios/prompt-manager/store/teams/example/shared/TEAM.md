# Example Team

This is an example team to demonstrate the team structure.

## Purpose

Teams enable:
- Shared context through team documents
- Role-based skill grants
- Organizational hierarchy

## How to Use

1. Copy this folder to create a new team
2. Update team.json with your team details
3. Define roles in roles.json
4. Add organizational structure in org.json
5. Add shared documents to the shared/ folder

# Effort Supervision

Observe arbitrary efforts discovered by Agent Manager and assess delivery against
their accepted outcomes. Read `docs/agent-system/EFFORT_SUPERVISION.md` and the
canonical `large-effort-supervision` skill for the method and authority boundary.

The runtime selects a bounded evidence cut and any healthy sample. The persisted
diagnostic allowance pays for observation, inference and sampling. Discovery-only
idle belongs to the standing service's shared accounting reference. Attribute
each assessment to its wake ID, effort references and AM run ID. Unknown cost
remains unknown.

The portable team definition defaults to disabled. This host's implementation
owner activated a bounded observation pilot on 2026-09-12 after owner tests;
configuration alone is not operational qualification. See the contract's current
implementation record and the owner heartbeat status for actual readiness.
Qualified steering requires the affected effort's actual AM grant. Director
Swarm retains portfolio amendments; workers retain their assigning orchestrator.

Supervision includes finding stale blockers, diagnosing premature stops and
coordinating qualified owner recovery. A newer resolution source is a reason to
reconsider, not permission to restart. Retain exact old executor identities,
provider policy and repair limits. Do not run a second writer or duplicate a
repair already assigned to an effort. Report a missing recovery owner or grant
as that specific gap, not as the already-repaired original failure.

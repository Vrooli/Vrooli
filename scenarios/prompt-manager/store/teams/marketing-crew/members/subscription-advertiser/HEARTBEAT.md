# Heartbeat: Subscription Advertiser

## Task Loop
1. Triage subscription SKU coverage state.
2. Review active subscription campaigns for open artifact slots.
3. Select the highest-leverage draft opportunities.
4. Produce drafts with verified feature claims and honesty flags.
5. Append draft entries to the declared team working state.
6. Check supersession on owned pending decisions.
7. Raise publish, coverage, or capability decisions only when warranted.
8. Record the ad-run knowledge entry.

## Handoff Shape
### Coverage triage summary
### Drafts produced
### Coverage-gap decisions raised
### Capability-gap decisions raised
### Supersessions
### Knowledge entry written

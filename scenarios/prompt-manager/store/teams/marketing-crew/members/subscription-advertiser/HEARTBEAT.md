# Heartbeat: Subscription Advertiser

Apply the resolved operating contract above.

## Task Loop
1. Triage subscription SKU coverage state.
2. Review active subscription campaigns for open artifact slots.
3. Select the highest-leverage draft opportunities.
4. Produce drafts with verified feature claims and honesty flags.
5. Append draft entries to the declared shared state.
6. Check supersession on owned pending decisions.
7. Raise publish, coverage, or capability decisions only when allowed by the contract.
8. Write the required ad-run knowledge entry.
9. End with HANDOFF.

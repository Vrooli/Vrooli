# Heartbeat: Subscription Advertiser

## Task Loop
1. Triage subscription SKU coverage state.
2. Read subscription artifact requests, publish logs, coverage snapshots, relevant research evidence, and recent subscription-lane ad-run entries.
3. Review active subscription campaigns for open artifact slots.
4. Select the highest-leverage draft opportunities.
5. Produce drafts with verified feature claims and honesty flags.
6. Append draft entries to the declared team working state.
7. Check supersession on owned pending decisions.
8. Raise publish, coverage, or capability decisions only when warranted.
9. Record the ad-run knowledge entry.

## Handoff Shape
### Coverage triage summary
### Artifact requests reviewed
### Drafts produced
### Coverage-gap decisions raised
### Capability-gap decisions raised
### Supersessions
### Knowledge entry written

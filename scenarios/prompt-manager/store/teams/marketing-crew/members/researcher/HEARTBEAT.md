# Heartbeat: Researcher

## Task Loop
1. Read `docs/marketing/research/README.md`, previous handoff, owned pending decisions, and recent researcher knowledge.
2. Run `prompt-manager skill read marketing-research-router`.
3. Review `shared/research-inbox.jsonl` for operator-fed alpha, cross-team requests, and bookmark-intelligence-hub exports when available.
4. If inbox signal is empty or stale, run a small proactive baseline scan with cited sources.
5. Classify each selected signal by intake source, collection mode, analysis method, and promotion target.
6. Append distinct observations with source references and honesty flags before proposing interpretation.
7. Write cross-team benchmark-adjacent entries when useful.
8. Check supersession on owned pending decisions.
9. Raise audience, post-type, hook, channel-strategy, skill/action/scenario, or capability-gap decisions only when warranted.
10. Record the audience-scan knowledge entry.

# Responsibilities: Feature Architect

## Primary Duties
- Design API contracts, data models, and component architecture.
- Consider edge cases and backwards compatibility.
- Present design options with trade-off analysis.

## Deliverables
- Design documents with API shapes/data schemas and backlog-ready proposed actions.

## Coordination Points
- Receive requirements from feature-lead.
- Deliver designs to feature-lead.
- Support feature-implementer with clarifications.

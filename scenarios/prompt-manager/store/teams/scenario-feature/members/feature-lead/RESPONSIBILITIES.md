# Responsibilities: Feature Lead

## Primary Duties
- Clarify requirements and define acceptance criteria.
- Manage scope and make trade-off decisions.
- Coordinate design, implementation, and review.

## Deliverables
- Feature specifications with acceptance criteria.
- Status reports to director-swarm.

## Coordination Points
- Receive feature requests from director-swarm.
- Assign work to architect, implementer, reviewer.
- Report completed features to marketing-crew.

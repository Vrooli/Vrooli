# Heartbeat: Portfolio Manager

## Task Loop
1. Review accepted portfolio decisions and mark supported applications.
2. Inspect current initiative and backlog state.
3. Check scenario-scoped proposals against existing initiative coverage before drafting anything new.
4. Identify the smallest portfolio correction that needs approval.
5. Record portfolio markers or snapshots.
6. Propose corrections when they are not duplicative.

## Handoff Shape
### Portfolio state
### Accepted decisions applied
### Coverage checks
### Proposed corrections
### Decisions raised
### Knowledge entries written

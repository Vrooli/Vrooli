# Run Task: Vision Walk Prep

## Task Loop
1. Read `prompt-manager skill read command-center-vision-walk-prep` and execute that
   capability within this member's existing authority and schedule.
2. Command Center owns the preparation contract, its sources, and its bounds. Do not
   maintain a separate collection procedure here.

## Run Decision

The published ledger entry is this run's product; `command-center walk publish` returns the
receipt that proves it survived the run. Report that receipt, the briefing's named gaps, and
any silent peer record. Do not restate the briefing as a response section — durable
continuity lives in the declared Source Ledger topics, not in a runtime snapshot. Never
write runtime output into the Config-class team store.

Choose one disposition and state its evidence: no-action, existing-action-reference,
new-action-candidate, cli-backlog, capability-work-item, prune, improve, or graduate. A
read-only preparation is normally `no-action`.

## Stop Conditions

The prep skill owns the stop conditions and the no-retry rule; follow the ones it declares.
A failed preparation is not a successful heartbeat merely because prose was produced. No
receipt means the briefing was not published, whatever the response says.

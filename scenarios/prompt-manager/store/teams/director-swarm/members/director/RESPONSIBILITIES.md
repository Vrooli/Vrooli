# Responsibilities: Director

## Primary Duties
- Set strategic priorities for Vrooli.
- Make decisions on resource allocation across teams.
- Approve or defer major initiatives.
- Resolve escalated conflicts.

## Deliverables
- Strategic priority list (Now/Near/Far).
- Decision log entries with reasoning.

## Coordination Points
- Receive intelligence from intelligence-officer.
- Receive strategy analysis from strategist.
- Issue priorities through operations-chief.
- Handle P0 escalations from any team.

# Heartbeat: Outcome Strategist

## Task Loop
1. Read the outcome charter declared in the contract.
2. Verify Command Center outcome surfaces exist.
3. If unavailable, write a blocked handoff and stop.
4. Apply accepted outcome decisions where supported.
5. Inspect metrics and dashboard gaps.
6. Raise outcome decisions only when grounded in real data.

## Handoff Shape
### Outcome signals
### Dashboard gaps
### Applied accepted decisions
### Recommendations needing approval
### Knowledge entries written

# Responsibilities: Fix Engineer

## Primary Duties
- Write regression tests that reproduce confirmed bugs.
- Implement minimal fixes addressing root causes.
- Run full test suites to verify no regressions.

## Deliverables
- Regression tests for every fixed bug.
- Minimal fix implementations with clean commit messages.

## Coordination Points
- Receive confirmed root causes from debug-lead.
- Report fix completion with test results to debug-lead.
- Flag blast radius concerns before proceeding.

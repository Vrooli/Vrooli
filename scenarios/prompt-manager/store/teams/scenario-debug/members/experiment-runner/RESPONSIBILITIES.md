# Responsibilities: Experiment Runner

## Primary Duties
- Design minimal experiments to confirm or reject hypotheses.
- Execute experiments with precise documentation.
- Report clear conclusions: confirmed, rejected, or inconclusive.

## Deliverables
- Experiment reports with setup, prediction, observation, conclusion.
- Diagnostic code used in experiments.

## Coordination Points
- Receive prioritized hypotheses from debug-lead.
- Report experiment results to debug-lead.
- Request hypothesis refinement when results are inconclusive.

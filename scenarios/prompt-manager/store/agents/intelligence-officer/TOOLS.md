# TOOLS

## Tool Access
`prompt-manager skill read <skill-id>`

## Primary Skills
- **swarm-manager-backlog-tools** — Initiative and backlog inspection commands.
- **scenario-readiness-review** — Secondary readiness evidence for initiative execution risk.

## Monitoring Approaches
- Initiative rollups and dependency graphs.
- Backlog item quality, missing detail, and approval gaps.
- Scenario health and test signals that materially affect active initiatives.
- Team output quality indicators when they change initiative risk.

## Usage Rules
- Always state confidence levels for signals.
- Flag urgent signals immediately, do not batch them.
- Distinguish signal from noise objectively.
- Do not drift into strategy recommendations; surface evidence and open questions instead.

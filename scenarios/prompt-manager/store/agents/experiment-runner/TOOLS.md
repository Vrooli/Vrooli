# TOOLS

## Tool Access
`prompt-manager skill read <skill-id>`

## Primary Skills
- **scientific-debugging** — Experiment design methodology.
- **e2e-testing** — End-to-end test execution.
- **unit-testing-architecture-steer** — Unit test design patterns.

## Testing Commands
- `vrooli scenario test <name>` — Run scenario test suite.
- `cd scenarios/<name> && make test` — Run tests via Makefile.

## Usage Rules
- Always predict the outcome before running the experiment.
- Keep experiments isolated — change only one variable at a time.
- Document all observations, even unexpected ones.

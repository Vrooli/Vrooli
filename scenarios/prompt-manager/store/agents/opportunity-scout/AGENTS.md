# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Review the existing Vrooli scenario list and their capabilities.
- Check current market trends in AI tooling and developer productivity.

## Workflow
1. **Scan landscape** — What are developers and businesses paying for? What is underserved?
2. **Review capabilities** — What can Vrooli already do? What scenarios exist?
3. **Generate combinations** — How could existing capabilities serve unmet needs?
4. **Draft opportunity briefs** — Structured format for each idea.
5. **Deliver to research-lead** — Raw opportunity portfolio for evaluation.

## Opportunity Brief Template
### [Idea Name]
- **Problem**: What pain point or need does this address?
- **Solution**: How would Vrooli solve this?
- **Revenue Model**: How does this generate revenue? (SaaS, one-time, internal tool)
- **Vrooli Advantage**: Why can Vrooli do this better/cheaper/faster?
- **Existing Assets**: Which scenarios or resources already support this?
- **Effort Estimate**: Rough sizing (S/M/L/XL).

## Coordination
- Receive research scope from research-lead.
- Deliver opportunity briefs to research-lead.
- Work with feasibility-analyst to refine promising ideas.

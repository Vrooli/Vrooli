# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Read the feature requirements and acceptance criteria from feature-lead.
- Review the target scenario architecture and existing patterns.

## Workflow
1. **Understand context** — Read scenario docs, existing code, and patterns.
2. **Design API** — Define endpoints, request/response shapes, error handling.
3. **Design data model** — Schema changes, migrations, relationships.
4. **Design UX flow** — Component hierarchy, state management, user interactions.
5. **Consider edge cases** — Error states, concurrent access, backwards compatibility.
6. **Present design** — Deliver to feature-lead with trade-off analysis.

## Skills
- `prompt-manager skill read api-steer` — API design guidance.
- `prompt-manager skill read storage-steer` — Data model guidance.
- `prompt-manager skill read cli-steer` — CLI interface design (if applicable).
- `prompt-manager skill read react-stability` — React patterns (if UI involved).
- `prompt-manager skill read ux` — UX design guidance.

## Coordination
- Receive requirements from feature-lead.
- Deliver design document to feature-lead for review.
- Support feature-implementer with design clarifications.

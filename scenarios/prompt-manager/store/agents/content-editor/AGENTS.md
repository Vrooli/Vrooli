# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Read the team shared doc for brand voice guidelines.
- Review the draft content to be edited.

## Workflow
1. **Read the draft** — Understand the intent, audience, and platform.
2. **Check accuracy** — Verify factual claims, dates, names, statistics.
3. **Edit for tone** — Ensure builder voice, remove corporate speak.
4. **Edit for clarity** — Cut fluff, tighten prose, improve flow.
5. **Format for platform** — Character limits, hashtags, thread structure.
6. **Return to marketing-lead** — Edited draft with change notes.

## Editing Checklist
- [ ] Factual claims verified or flagged.
- [ ] Builder voice preserved (first person, conversational).
- [ ] No overpromising or capability misrepresentation.
- [ ] Platform formatting correct (character counts, structure).
- [ ] Sensitive data removed (paths, keys, internal names).

## Coordination
- Receive drafts from marketing-lead.
- Return edited versions with change notes.
- Flag any content that needs factual verification.

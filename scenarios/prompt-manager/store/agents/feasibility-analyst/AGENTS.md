# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Review the Vrooli scenario inventory and their capabilities.
- Understand the ideas being evaluated.

## Workflow
1. **Receive ideas** — From research-lead with opportunity briefs.
2. **Map to capabilities** — Which existing scenarios support this idea?
3. **Identify gaps** — What would need to be built new?
4. **Assess dependencies** — What resources, integrations, or scenarios are required?
5. **Estimate effort** — T-shirt sizing with reasoning.
6. **Identify risks** — Technical, operational, or dependency risks.
7. **Report to research-lead** — Feasibility assessment for each idea.

## Assessment Template
### [Idea Name] - Feasibility
- **Existing Assets**: [Scenarios and resources that already support this]
- **Gaps**: [What needs to be built]
- **Dependencies**: [Required resources, integrations]
- **Effort**: [S/M/L/XL] because [reasoning]
- **Risks**: [Technical risks, dependencies, unknowns]
- **Recommendation**: [Feasible/Stretch/Infeasible] with confidence level

## Coordination
- Receive ideas from research-lead.
- Deliver feasibility assessments.
- Work with opportunity-scout to refine ideas based on capability reality.

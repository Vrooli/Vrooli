# TOOLS

## Tool Access
`prompt-manager skill read <skill-id>`

## Primary Skills
- **interoperability-steer** — Understanding scenario composition.
- **progress** — Current state of Vrooli capabilities.

## Capability Discovery
- `ls scenarios/` — List all existing scenarios.
- Read scenario PRDs and docs for capability understanding.
- Check scenario dependencies and resource requirements.

## Usage Rules
- Always check existing scenarios before estimating new work.
- Be honest about effort — no sandbagging, no wishful thinking.
- Flag technical risks and dependencies explicitly.

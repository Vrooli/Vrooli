# TOOLS

## Tool Access
`prompt-manager skill read <skill-id>`

## Primary Skills
- **swarm-manager-backlog-tools** — Initiative and backlog inspection commands.
- **progress** — Understanding current Vrooli state.

## Strategic Analysis Approaches
- Portfolio-fit analysis across current initiatives.
- SWOT analysis (Strengths, Weaknesses, Opportunities, Threats).
- Trade-off matrices for comparing options.
- Bottleneck identification and theory of constraints.

## Usage Rules
- Present multiple options, never single recommendations.
- Always identify opportunity costs.
- Distinguish gates (irreversible) from doors (reversible).
- Recommend portfolio changes and supplemental work, not direct execution.

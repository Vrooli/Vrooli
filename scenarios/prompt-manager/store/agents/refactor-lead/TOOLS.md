# TOOLS

## Tool Access
`prompt-manager skill read <skill-id>`

## Primary Skills
- **refactor** — Refactoring guidance and patterns.
- **refactor-scope** — Session boundary enforcement.
- **progress** — Priority ordering for refactoring targets.
- **code-cleanup** — Anti-pattern identification.

## Usage Rules
- Always verify test coverage before approving refactoring.
- Prefer many small changes over one large change.
- Behavior must be preserved — no feature additions during refactoring.

# AGENTS

## Start of Session
- Read SOUL.md to align identity.
- Read TOOLS.md for available refactoring skills.
- Review the team shared doc for refactoring principles and safety protocols.
- Identify the target scenario and its current test coverage.

## Workflow
1. **Assess current state** — Read scenario code, docs, and test suite.
2. **Identify opportunities** — Assign complexity-analyst to find hotspots.
3. **Prioritize** — Rank opportunities by impact (complexity reduction) vs risk (test coverage).
4. **Plan** — Break into small, independently-verifiable steps.
5. **Delegate** — Assign refactor-engineer to execute, regression-guard to validate.
6. **Verify** — Confirm all tests pass after each step.
7. **Report** — Summary of improvements to director-swarm.

## Skills
- `prompt-manager skill read refactor` — Refactoring guidance.
- `prompt-manager skill read refactor-scope` — Refactoring session boundaries.
- `prompt-manager skill read progress` — Priority ordering.

## Coordination
- Receive refactoring targets from QA team (code smell findings) or director-swarm.
- Assign work to complexity-analyst, refactor-engineer, regression-guard.
- Report improvements to director-swarm and QA team.

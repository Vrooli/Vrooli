# TOOLS

## Tool Access
- `prompt-manager team member-context scenario-qa qa-contrarian`
- `prompt-manager team decision-list scenario-qa ...`
- `prompt-manager team decision-list <peer-team> ...` — read-only across peer teams (marketing-crew, monetization, infra-health, etc.)
- `prompt-manager team knowledge-list scenario-qa ...` — read bug-investigation-report/*, quality-audit/*, qa-run/* for challenge candidates
- `prompt-manager team knowledge-add scenario-qa --topic="challenge-report/..."` — write append-only challenge-note entries
- `prompt-manager team knowledge-add scenario-qa --topic="challenge-resolution-record/..."` — write latest-state challenge resolution records
- `swarm-manager` CLI — read-only for backlog item review
- `vrooli help`

# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Read the content brief from marketing-lead.
- Read the x-dev-log skill for dev log methodology.
- Review recent scenario activity for content material.

## Workflow
1. **Receive brief** — Topic, angle, platform, target audience.
2. **Mine data** — Query scenario APIs for recent activity, commits, agent runs.
3. **Score for interest** — What is most engaging? Failures-then-recovery, milestones, surprises.
4. **Draft content** — Write in builder voice, platform-appropriate length.
5. **Add sources** — Cite specific commits, agent runs, or data points.
6. **Submit for review** — Send draft to marketing-lead.

## Content Types
- **X/Twitter dev logs** — 3-7 tweet threads about recent work.
- **Blog posts** — Longer-form technical narratives.
- **Announcements** — Feature launches, milestone celebrations.
- **Behind-the-scenes** — How agents work, interesting debugging stories.

# AGENTS

## Start of Session
- Read SOUL.md for identity alignment.
- Identify the target scenario and its test infrastructure.
- Review existing test files and test commands.

## Workflow
1. **Map test infrastructure** — What test framework, what test commands, what CI.
2. **Assess current coverage** — Run tests, check which behaviors are covered.
3. **Identify gaps** — What critical paths lack tests?
4. **Risk-weight gaps** — What untested behavior would cause the most damage if broken?
5. **Recommend improvements** — Specific test outlines for highest-risk gaps.
6. **Report to qa-lead** — Coverage report with prioritized recommendations.

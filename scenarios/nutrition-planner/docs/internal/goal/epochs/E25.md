## Modules and budgets

Accepted R12.2/R13.2 requires step-local specified equipment/settings to remain visible with recipe method actions. The current `RecipeStep` contract carries ID, instruction, dependencies, inputs and outputs; `Recipe` separately carries `required_appliances`. The API maps method steps through `internal.MethodStep`, and the recipe map already renders each step's linked inputs/dependencies/outputs. Add optional step-local equipment and settings fields, carry them through the existing recipe revision/API path, and render them only for that declared step. This slice does not alter the cooking session view; its rendering can follow after E24's same-file proposal is resolved.

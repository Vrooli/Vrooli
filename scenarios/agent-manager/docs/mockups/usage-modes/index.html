Usage modes: stretch your plan, and see whether it worked

Six surfaces, each drawn for desktop and for a phone. The app has one dark theme today, so there is no light variant to draw; the tokens below are copied from ui/src/styles/global.css.

Sample data only. Every number, name, time and percentage here is invented to show layout and wording. None of it is measured from your accounts. Wherever a result is shown, its strength of evidence is shown beside it.

On a narrow screen the desktop mockups scroll sideways inside their own box; the page itself does not.

Find out properly, by chance assignment

New launches of the chosen roles are split by chance between the usual model and the cheaper one, so the comparison is fair. The wait is estimated, not promised.

How long until an answer

Probably 3 to 6 weeks, and it could take longer.

Needs about 40 finished launches per side. At 23 launches a week this takes roughly 3.5 weeks if nothing changes; slow weeks or unknown outcomes stretch it. We'll update the estimate daily.

While it runs, about half of these launches use the cheaper model, whatever its quality. You can stop at any time and you'll keep what was learned.
Fine print in plain words

Running sessions are never changed. Choosing a model yourself still wins. Results appear in Evidence as "Randomized".

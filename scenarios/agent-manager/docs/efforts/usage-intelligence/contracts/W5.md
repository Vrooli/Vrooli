# W5 contract — attribution, recommendations, coverage, compare

Generated 2026-10-29 from `packages/proto/schemas/agent-manager/v1/measures/measures.proto`
(service `MeasuresService`). TypeScript: `packages/proto/gen/typescript/agent-manager/v1/measures/`.
All four are read-only Measures RPCs (agent identity can read them). Timestamps are RFC 3339 UTC;
empty means unknown. Points are percentage points of the named provider window and are
estimates: render them as "≈N pts", never as exact per-session percentages.

| RPC | Request | UI surface |
|---|---|---|
| `UsageBurners` | `provider`, `group_by` (session \| run \| profile \| workload \| model \| runner \| modality \| tool_kind; default session), `since`, `run_id`, `limit` (20) | Usage page "What's using it" (group-by switch), run usage panel (`run_id`) |
| `UsageRecommendations` | `provider`, `run_id`, `limit` (20) | Usage page Recommendations; run panel (`run_id`) |
| `UsageCoverage` | `since` (default 7 days ago) | Usage › Coverage tab, header "coverage 97%" chip |
| `UsageCompare` | `left`, `right` (`CohortSelector`), `change_binding`, `provider` | value comparison (A11); CLI first |

## UsageBurnersResponse

- `windows[]` = `UsageWindowAttribution`, one per current provider window (same scopes as
  `UsageForecast.windows`, matched by `provider`+`pool`+`window`).
  - `observed_increase_points` over `[period_start, period_end]`; `attributed_points`,
    `unattributed_points` (render as "unattributed / off-disk"), `other_points` +
    `other_burners` (rows beyond `limit`). Invariant:
    `Σ burners.points + other_points + unattributed_points = observed_increase_points`.
  - `burners[]` = `UsageBurner`: `key`, `label`, `points`, `share`, `tokens` (`UsageTokens`
    input/cached_input/cache_creation/output/total), `weighted_tokens`, `sessions`, `runs`,
    `turns`, `run_ids[]` (≤10, drill-in → run detail), `runner`, `model`, `profile_id`,
    `workload` (single-valued or empty), `first_at`, `last_at`, `modality` (`UsageModality`:
    images_in, images_in_high_detail, estimated_image_input_tokens, images_out, web_searches,
    web_fetches, audio_in, tool_calls, tool_kinds[]), `source` (indexed \| agent_manager \| mixed).
  - `calibration` = `UsageCalibration`: `method` (fitted \| scaled \| none), `weights[]`
    (`UsageModelWeight`: runner, model, cached_input_tokens_per_point, input/cache_creation/output
    weights, source price_book \| tier_prior \| fallback), `r_squared`, `slices` (blocks of ≥3
    points), `off_disk_points_per_hour` (unattributed points per hour), `note`.
    Show as a "how this is estimated" disclosure.
  - `pending_tokens`: usage after the newest reading (not yet in any percent).
  - `metered_lines[]` = `UsageMeteredLine` (kind, count, state known \| estimated \| unknown,
    amount, note): non-token work (Codex credits, web search, image generation, scenario
    calls). Own line; never added to points.

## UsageRecommendationsResponse

- `recommendations[]` ranked (`rank` 1 = largest `est_weekly_quota_points_saved`):
  `rule` (R-model \| R-context \| R-fanout \| R-friction \| R-idle \| R-image), `lever`,
  `target_kind`/`target_id`/`target_label`, `provider`/`pool`/`window` (the window the saving is
  in), `est_weekly_quota_points_saved` ("−N%/wk"), `confidence` (high \| medium \| low),
  `action` (one sentence to show), `rationale`, `consumer_points`, `evidence_refs[]`
  (`kind` run \| session \| file \| episode \| image \| profile \| workload, `id`, `label`),
  `metrics[]` (`name`, `value`, `unit`). Row → evidence panel.
- `rules[]` = `UsageRuleStatus` (rule, fired, rows, candidates, reason): show a muted
  "rule did not fire: reason" line for each family that did not fire.
- `dominant_consumer` / `dominant_consumer_label`: the session with most points.

## UsageCoverageResponse

- `roots[]` and `totals` = `UsageCoverageRoot`: `kind`, `harness`, `files`, `indexed`,
  `with_usage`, `owned`, `excluded`, `pending`, `unreadable`, `bytes`, `captured_bytes`,
  `captured_share` (0..1, the header chip), `turns`, `usage_reports`, `issues[]` (path, reason;
  ≤50 per root: "N files unreadable · details →").
- `method`: text describing the independent disk-scan comparison (show under details).

## UsageCompareResponse

- `left`/`right` = `UsageCompareSide`: runs, successful_runs, priced_runs, tokens,
  weighted_tokens, points, points_per_success, tokens_per_success, success_rate,
  window_start/end. `points_per_success_change` (negative = better), `verdict`
  (improved \| regressed \| unchanged \| insufficient), `caveats[]`.

All responses carry `provenance` (source tables, window), `definition_id`, and (burners,
recommendations, compare) `validity`.

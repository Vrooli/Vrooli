# Quickstart

1. Run `make start` from `scenarios/vrooli-onboarding`.
2. Select one or more scenarios. Vrooli derives their required resources.
3. Provision declared credentials through the credential cards. Values are sent
   only to the control plane and are never persisted in browser state.
4. Review host requirements and operating-mode recommendations.
5. Use Validation to resolve required missing or unsupported checks.

Reopening the UI reloads the effective operator state from
`.vrooli/operator-state.json`.

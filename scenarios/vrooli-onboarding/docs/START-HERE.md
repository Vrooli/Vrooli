# Vrooli Onboarding V2

Vrooli Onboarding is the scenario-first operator surface for configuring Vrooli.
It derives resources, credentials, host requirements, operating choices, and
readiness from manifests plus `.vrooli/operator-state.json`.

Start the scenario with `make start` and open its lifecycle-managed UI. The
Integrations step is intentionally deferred until Integration Hub is available.

See [Quickstart](QUICKSTART.md), [Wizard flow](WIZARD_FLOW.md), and
[Configuration](reference/configuration.md).

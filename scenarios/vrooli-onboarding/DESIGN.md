# Design — Vrooli Onboarding V2

The product is scenario-first. It projects manifest declarations into a single
operator workflow, commits choices atomically to operator state, and reloads
that state on re-entry. Credentials are descriptor-driven and provisioned only
through the control plane. Integration Hub remains visibly deferred.

The UI is responsive, keyboard-operable, iframe-safe, and uses a compact
progress rail so all eight V2 steps fit within embedded desktop viewports.

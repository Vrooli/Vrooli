# Goal — React Component Library rehabilitation

**Destination.** RCL offers a dependable, deliberately small core of reusable React assets; humans and agents discover, adopt, improve and upgrade them through clear workflows. Its design studio is discoverable from normal navigation and carries scenario page design through durable composition, review and governed implementation. Existing scenario design templates work consistently. Runtime code and delivery machinery become simpler and easier to maintain.

**Revision.** `rcl-rehabilitation-20260930-1`, prepared 2026-09-30; operator authorized execution 2026-10-01. The earlier UX campaign's 12/12 acceptance is historical evidence, not acceptance of this destination.

**Constraints.** Reuse first; certify the selected core and necessary dependency closure, not the full catalog. Shared package consumption is the default; deliberate local composition/ejection preserves provenance. Prompt Manager is a bounded proving consumer. Preserve saved designs, user data, public contracts and other agents' work. Use governed asset drafts and dependency operations. No release-directory edits, Swarm Manager, Plan Manager or git operations. Operator commits and starts delivery.

**Delivery.** Orchestrated epochs per `large-effort-orchestration`: Luna-high orchestrator, one Luna-medium worker per epoch, rare Sol supervision. Refactor epochs replace and delete whole duplicate concepts; feature growth needs an admission budget. Never trade away correctness, accessibility or recovery for a green metric.

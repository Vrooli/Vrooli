# Glossary

- `Preview Surface`: A UI container that hosts scenario preview behavior (single preview or workspace pane).
- `Pane`: One workspace tile that has independent app selection, URL history, and logs mode.
- `Bridge`: `@vrooli/iframe-bridge` communication channel between host UI and preview iframe.
- `Open Mode`: Tab-switcher scenario launch behavior (`single-preview`, `replace-focused`, `add-pane`).
- `Preview Overlay`: Transient loading/restart/error messaging layered on the preview iframe.

Make every Web Console agent conversation durable, attributable, searchable, and recoverable across pane closure, process exit, browser disconnect, API restart, metadata drift, and partial failure. Replace the fragmented session-deletion behavior with one explicit lifecycle, reconcile surviving transcripts into first-class records, and connect Web Console continuity to Agent Manager's cross-run retrieval capability without creating a second search authority.

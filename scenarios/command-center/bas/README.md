# Command Center — BAS Playbooks

This directory holds the test-genie / Browser Automation Studio assets that validate the Command Center UI.

## Structure

```
bas/
├── actions/   # shared reusable action fragments (empty today)
├── cases/     # per-target playbook cases (grouped by requirement target)
│   └── 01-foundation/   # OT-P1-001 UI shell + OT-P0-002 Mission Control slice
├── flows/     # end-to-end user journey playbooks that cross multiple targets
├── seeds/     # seed helpers (stubbed; no seed.go or seed.sh yet)
└── registry.json  # auto-generated by `test-genie registry build`
```

## Selectors

All `data-testid` values referenced here are registered in `ui/src/consts/selectors.ts` so host scenarios can resolve them via `@vrooli/iframe-bridge` without string drift.

## Regenerating the registry

After adding or renaming a case or flow, rebuild the auto-generated registry:

```bash
test-genie registry build
```

Run from the scenario root. The command rewrites `bas/registry.json` (and refreshes timestamps/order) — never hand-edit it.

Settings redesign — the section model

Corrected to how the board actually renders: a room cycles through sections (beats); each section spotlights a hero signal in a layout (a composition's slots — one primary + N secondaries), and some sections swap in a bespoke single-control layout. Drawn in the real palettes with the real rooms, signals, and layouts. Click around: open a room, select its sections, pick a look, browse signals, or drop to Operator mode.

Every place that needs code shows a “Hand to an agent” button that copies a ready prompt.
Command Center

Sections are the unit

Room → sections (beats) → per-section layout & bindings — matching hive's 5 beats and forge's 6, including the bespoke override sections.

Layouts aren't form-authored

New layouts declare slots in code, so "Layout" is a picker + a "Hand to an agent" button — never a fake form.

Menus filter by measurement kind

A "single number" slot only lists scalar signals; a "table" slot lists row signals. The shape rule, spoken plainly.

Add / delete / reorder everywhere

Rooms and sections reorder by drag, add with a card, delete with confirm. Looks and signals add/delete too.

# Secrets Manager

Dark chrome security dashboard for discovering, validating, and provisioning secrets required by Vrooli resources

## 🚀 Quick Start

### Development
```bash
# Install dependencies
npm install

# Start in development mode
npm run dev

# Build TypeScript
npm run build
```

### Building for Distribution
```bash
# Build for current platform
npm run dist

# Build for all platforms
npm run dist:all
```

This project has a Bash script `sum.sh` whose implementation is a stub.

Implement it so that running `bash sum.sh A B` prints the integer sum of the two
whole-number arguments A and B on a single line, with no extra output.

Examples:

    bash sum.sh 2 3    # prints: 5
    bash sum.sh 10 -4  # prints: 6
    bash sum.sh 0 0    # prints: 0

Only edit `sum.sh`. Do not add new files.

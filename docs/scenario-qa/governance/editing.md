# Scenario QA Editing Rules

## Authority

`docs/scenario-qa/` is stable plan-of-record canon owned by the `scenario-qa` team. Runtime execution rules live in the prompt-manager team store; this folder records durable strategy, operating structure, taxonomy, and methods.

## Change Flow

Changes to this plan of record go through operator-approved decisions. Use `bug-resolution-proposal` for bug-report taxonomy changes and scenario-qa operating changes. Use `meta-self-improvement` for new or retired method entries that affect shared agent-system technique discipline.

## Direct Edits

Agents do not directly edit scenario-qa PoR files during heartbeat work. They may propose changes through the owning decision context, cite the affected manifest entry, and include the validation commands from [`adoption-validation.md`](adoption-validation.md).

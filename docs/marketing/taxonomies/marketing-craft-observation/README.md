# Marketing Craft Observation Taxonomy

Canon for marketing-specific production lessons that are not research evidence, code bugs, or cross-team friction.

Use this only when the lesson belongs to marketing craft. Broken behavior goes to `report-bug`; system/process friction goes to `report-friction`; missing tooling that blocks marketing work becomes a `capability-work` decision.

## Signal types

| Signal type | Destination | Use |
|---|---|---|
| `post-type-craft` | `marketing-craft-observation/<post-type>/<slug>` | A repeated lesson about a specific post type or its paired skill. |
| `rich-media-craft` | `marketing-craft-observation/rich-media/<slug>` | A repeated lesson about image, video, scene, asset, or prompt-template production. |
| `campaign-lesson` | `marketing-craft-observation/campaign/<slug>` | A campaign postmortem lesson that is not yet durable campaign canon. |
| `publishing-workaround` | `marketing-craft-observation/publishing/<slug>` | A marketing-specific publishing workaround that may become channel canon, scheduler work, or a capability gap. |

## Promotion

Brand-manager drains these observations. Each entry must name a target direction: skill edit, post-type doc, post-technique doc, strategy canon, channel rule, scenario/config change, `capability-work`, or retirement.

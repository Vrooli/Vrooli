# Campaign Lessons

Post-campaign reflections and one-off observations that might eventually distill into `STRATEGY.md` guideline updates, `CHANNELS.md` rule refinements, or skill improvements.

**Promotion target:**
- Observed voice / positioning pattern → `brand-guideline-update` → `STRATEGY.md` revision.
- Observed platform-specific pattern → `channel-update` → `CHANNELS.md` revision.
- Observed campaign-structure pattern → `notebook-promotion` proposing a new skill or campaign-template.

**Retirement signal:** pattern has been promoted AND the original entry's lesson now lives in the target canon / skill.

**Revisit marker (file-level):** revisit after 14 heartbeats.

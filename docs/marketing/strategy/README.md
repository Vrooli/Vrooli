# Marketing Strategy

This folder contains directional marketing canon: voice, audience, campaign, channel, brand, asset, image-style, and reusable strategy-pattern documents.

## Strategy Documents

| Document | Purpose |
|---|---|
| [`STRATEGY.md`](STRATEGY.md) | Voice canon, positioning principles, samples, anti-patterns, and source-material discipline. |
| [`AUDIENCES.md`](AUDIENCES.md) | Audience personas and update rules. |
| [`CAMPAIGNS.md`](CAMPAIGNS.md) | Active campaign index and launch proposal surface. |
| [`CHANNELS.md`](CHANNELS.md) | Per-platform publishing rules and channel strategy. |
| [`BRAND.md`](BRAND.md) | Visual identity navigation hub. |
| [`ASSETS.md`](ASSETS.md) | Canonical brand asset registry and usage rules. |
| [`IMAGE_STYLE.md`](IMAGE_STYLE.md) | AI image generation style guide and prompt directives. |
| [`patterns/`](patterns/README.md) | Cross-cutting marketing strategies that span multiple post types. |

## Extension Rules

Add new directional canon here when it changes how marketing chooses audiences, messages, channels, campaigns, visual posture, or strategic patterns.

Use [`../catalogs/`](../catalogs/) for entity inventories, [`../methods/`](../methods/) for repeatable techniques, and [`../evidence/`](../evidence/) for supporting research or measurements.

# Monetization Strategy

This folder holds directional monetization canon: what the strategy is, which delivery tiers exist, how pricing should be reasoned about, and how prospects move through the funnel.

## Strategy Documents

| Document | Purpose |
|---|---|
| [`STRATEGY.md`](STRATEGY.md) | Monetization posture, principles, long-term directions, and cross-team coordination. |
| [`TIERS.md`](TIERS.md) | Delivery tiers, activation triggers, guardrails, and pricing implications. |
| [`PRICING.md`](PRICING.md) | Pricing matrix, principles, undecided areas, and benchmark dependencies. |
| [`FUNNEL.md`](FUNNEL.md) | Acquisition, activation, expansion, retention, upsell, advocacy, and telemetry dependencies. |

## Extension Rules

Add new strategy docs only when a stable directional concept outgrows these four files. Do not place SKU inventories here; use [`../catalogs/`](../catalogs/README.md). Do not place benchmark evidence here; use [`../evidence/`](../evidence/README.md).

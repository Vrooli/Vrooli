# Revenue Line: Lead Generation (for local service businesses)

- **Status:** `candidate`
- **Revisit trigger:** *"Revisit when at least one property-services scenario is deployable as a thin tool AND one local-service prospect signs a pilot agreement."*
- **Productization target:** [`property-services` add-on](../catalog/addons/property-services.md)
- **Legal surface:** TCPA (US telemarketing), CAN-SPAM (email), GDPR (if international), state-level rules on B2B vs B2C lead sales. Non-trivial; requires explicit legal review before first paid engagement.

## Hypothesis

Local service businesses (power washing, landscaping, flippers, solar installers, roofers) will pay per-lead or per-close for geo-targeted leads generated by Vrooli's data + AI capabilities. If it works for us, we can productize the underlying tool into the `property-services` add-on.

## Why this is the strongest candidate services line

1. **High capability reuse** — the `property-services` add-on already scopes most of the underlying tooling (geo scanning, visualization, estimating). Running lead-gen internally builds the same tools we'd productize.
2. **Immediate revenue is realistic** — per-lead or per-close pricing is well-established in this market; prospects understand it without education.
3. **Clean conversion path** — "we built you a tool that generates these leads; now subscribe to the add-on and run it yourself" is a concrete, linear pitch. Conversion doesn't require re-framing the relationship.

## Activation discipline (from REVENUE_LINES.md)

On promotion to `active`, this line must have all four:

1. **Validation hypothesis** — which vertical within property-services is this proving (power washing ≠ roofing ≠ solar)?
2. **Fixed-duration pilot** — concrete end date, not "ongoing."
3. **Productization target** — `property-services` add-on (already documented).
4. **Sunset or convert clause** — by date X, productize and hand off, or stop.

See [REVENUE_LINES.md](../REVENUE_LINES.md) for the full services-trap discipline.

## Notes

- Legal surface check is the single biggest gate before activation. Do not skip.
- Start with one vertical, not a basket. Vertical-specific pricing and regulatory context differ sharply.

# Review Feedback

Reviewers and contrarians provide evidence about team work. They record the
review note in their own Source Ledger scope and attach it to the single Swarm
Manager work item that owns the proposed correction.

Each note names the reviewed work, evidence, failure mode, author or team, and
recommended next action. The operator dispositions the work item in Swarm
Manager. The next heartbeat reads that disposition and either continues,
files a bounded follow-up, or archives the note.

Review notes are append-only. A later note explains a changed assessment and
retains the provenance needed to understand the transition. Reviewers may read
peer-team context but write only to their own team scope.

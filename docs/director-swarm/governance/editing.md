# Director Swarm PoR Editing

## Authority

The director-swarm plan of record is operator-curated canon owned by the `director-swarm` team. Agents propose changes through approved decisions; they do not edit canon directly during heartbeat work.

## Change Flow

| Change | Decision context |
|---|---|
| Portfolio ranking, roadmap themes, and sequencing interpretation | `initiative-portfolio` |
| New initiative framing | `initiative-proposal` |
| Supporting backlog work under existing initiatives | `initiative-supplement` |
| Backlog or initiative readiness judgment | `initiative-readiness` |
| Command Center metric gaps or missing data pipelines | `outcome-gap` |
| Outcome-driven portfolio emphasis changes | `outcome-direction` |
| Operator vision or architecture drift signals | `vision-update` |

Accepted decisions are executed by the operator. Commit messages cite the decision id.

## Direct Edits

Direct edits are limited to operator migration work, mechanical link repair, and explicitly approved canon updates. Live initiative state belongs in Swarm Manager, not in this plan of record.

# Retired split native supervisor experiment

Archived source from the source-only experiment, 2026-11-11. The parent selected
one ordinary actual-operator native boot supervisor instead of a permanent root
parent plus private user worker. These `.txt` snapshots are retained research,
not compiled product code or qualified native execution. They preserve the
credential/Job/launchd/lifetime/root-RPC investigation and prior fixtures.

The retained product protections are sealed boot publication, actual operator
identity, bounded source-pointer handling, disabled setup fencing, exact image
binding, unsupported-release status and refusal to run user-owned SDA as root.
No live native account/service/logon/device effect occurred in this experiment.

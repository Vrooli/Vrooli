# .vrooli/work/delivery — delivery-team homes

One folder per delivery team, named by team id (matching
`scenarios/prompt-manager/store/teams/<team-id>/`). This folder is the team's working
ledger. The team's identity/members/coordination stay in the prompt-manager team store,
linked here by the team's `homePath` field.

See `../README.md` for the model and
`docs/internal/delivery-reliability-research/migration/PHASE1-RELOCATE.md` for the
relocation runbook and old→new mapping.

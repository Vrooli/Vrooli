Findings that expand the delivery target:

- **Question indexing exists in two concrete forms.** CLI Health's command index embeds measure intent plus authored Questions. Search Hub's provider index stores multiple answer-space/intent/example vectors for routing. R09/R10's original bounded investigation did not establish these mechanisms; the specialist report now does. Neither mechanism alone proves generated-question multi-view source-passage indexing. Preserve routing versus evidence-unit scope.
- **Declared format support overstates the current complete path.** Current raster doc-ocr output is placeholder labelling, not observed OCR text; document-manager's resource runner/response adaptation and publication wiring require qualification. Mounted enrichment has no wired Gateway. Do not index placeholder labels, printable binary strings or empty decoded units as successful evidence. Resource and scenario owners retain those repairs; the report maps their exact source contracts.
- **Integration Hub is an API-key metadata pilot, not an OAuth-ready product.** No UI was observed. Its asserted owner header and unverified bearer hash are not the shared verified-principal boundary; connection/global ID, authority ref, operation fingerprint and current status-only probe/refresh seams need maturation. The team owns this early capability rather than requiring a human to generate one-off tokens.
- **Embedding freshness needs recipe-aware source invalidation.** Current source ContentHash shortcuts can skip before a changed view/prompt is composed; model/chunk-policy checks alone do not establish a general view recipe. Stable evidence units, ordinal-based vector points, synthetic hints and retained serving generations have different identities/lifetimes.
- **Private forwarding must be assessed at shared transport as well as the explicit adapter.** The final private-federation report narrows R02's earlier inspection: descriptor-header application is not proof that verified-agent provenance never propagates. Complete authenticated human/object/audience semantics still require concrete owner-backed qualification.

- Unselected: exact folders, grants, file-size/language/format policy, vision/multimodal scope, email name/UX/write behavior, OAuth client type/callback, cost limits and numerical search-quality thresholds.

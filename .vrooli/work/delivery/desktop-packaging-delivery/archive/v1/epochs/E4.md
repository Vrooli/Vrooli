## Modules and budgets

1. **Shared strategy seam — `packages/delivery-ramp-go`.** Register
   `wails-inprocess` as Go-API-only and keep non-embeddable or non-Go scenarios
   eligible for other strategies. Preserve ramp-neutral exported types and
   the `electron-sidecar` and `electron-optimized` paths.
2. **Desktop generator/builder/target — `scenarios/scenario-to-desktop`.**
   Add the Wails v3 generator and builder under the E2 strategy registry.
   Mount Connect handlers on the Wails asset server; do not open a TCP API
   listener. Keep output under `platforms/wails-inprocess/`. Emit the shared
   `packaged-launch.v1` marks and `webview_*` process roles. Implement the
   Linux WebDriver adapter through `webkit2gtk-driver`; no BAS changes.
3. **Embeddable API contract — `scenarios/scenario-to-desktop`** (and only
   owner-approved reference-scenario paths). A Go API must expose an
   importable constructor returning its `http.Handler` and lifecycle
   start/stop hooks. Prove that contract on reference APIs before proposing a
   template-wide change. Do not modify template-manager; prepare a reviewable
   owner proposal in the E4 handoff.
4. **Host/dependency setup — root host-tool owners and the goal
   `INSTALLS.md`.** Declare only the preapproved WebKitGTK/GTK headers and
   WebDriver host tool in root `internal/tools/<name>/tool.json`, and reference
   them from `scenarios/scenario-to-desktop/.vrooli/service.json` `hostTools[]`
   per `docs/configuration/host/tools.md`. The operator runs `sudo vrooli setup`
   from the `Needs operator` item. Agents never run sudo.
   Add Wails Go/CLI dependencies only through Scenario Dependency Analyzer.
5. **Measurement — published `performance-health` contracts are read-only.**
   Capture Wails process/launch evidence with the shared contract. Measure the
   NVIDIA/DMABUF mitigation both enabled and disabled under the same journey
   and host conditions. Record unavailable marks with reasons.
6. **Shared generated contracts — `packages/proto` only if required.** Use
   the owning `make generate SCENARIO=<owner>` and
   `make verify-committed-gen`; never hand-edit generated output.

Estimate: 30 work units from the approved QUEUE slice. Feature growth cap is
1.5× expected size (3300 net runtime lines). Tests may grow only for newly
covered behavior. Host setup, journeys needing the operator's packages and
macOS qualification may remain named waits while other in-scope work proceeds.

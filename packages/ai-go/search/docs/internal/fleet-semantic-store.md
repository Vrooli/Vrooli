# Owner-bound Qdrant semantic store

`FleetSemanticStore` is the shared steady-state query/upsert/delete seam for one trusted Qdrant owner and alias. Construct it through `QdrantFleetAdapter.NewSemanticStore` or an owner lifecycle factory. Construction requires a complete immutable recipe embedder, a runtime role, a positive peak estimator, a semantic operation admission issuer, and an owner catalog that implements `FleetSemanticOperationLedger`.

Requests carry an operation ID, tenant scope, active arm and exact recipe ID. Upsert adds one stable source ID, a positive owner sequence, one document and payload. Delete supplies distinct source IDs with their positive owner sequence. The API reserves each source's sequence under the owner+alias operation fence before vector I/O and rejects equal/older sequences from another operation or any source with a pending foreign operation. Delete source entries are sorted before hashing/admission. This lets an owner process asynchronous source changes without an older write overwriting a later update or delete.

The store reads the cataloged active generation and Qdrant alias before query embedding. Query and delete filter by full recipe, owner, alias, arm and reserved `fleet_tenant_id`; `user_id` may remain null for unowned records. Upserts bind the same tenant scope, source, recipe, owner, alias, arm, runtime role, caller ID and rights/quality evidence hashes into reserved payload keys. Request payloads cannot override those fields.

Every operation plan binds the exact operation ID, normalized request SHA-256, tenant, owner, alias, collection, arm, full recipe identity, role, active generation version, dimensions, point/source counts, request bytes and caller rights/quality evidence. A trusted estimator supplies positive peak bytes; a separate owner issuer returns an exact-request receipt with an observation time and no more than one minute of validity. Receipt validation happens before embedding and vector I/O. The issuer must authorize the caller/tenant and verify the evidence artifacts; local digest-shape validation is not a rights decision.

The current `FleetSemanticAttribution` URI and digest fields are references, not proof that the evidence is authentic or current. The semantic issuer must verify rights against fresh owner-controlled `RightsDecisionReceiptExpectation` facts and use authenticated owner evidence; a receipt's self-hash alone is not authentication. Search Hub currently has no such owner expectation/receipt source or semantic issuer, so production construction remains unavailable.

The durable owner ledger stores Started and Completed records. A completed same-ID/same-request call returns the stored result without Qdrant I/O or another generation counter increment. Reusing an ID with a different request digest fails. For an interrupted upsert, the adapter uses the exact tenant-scoped point ID and checks its owner/alias/arm/tenant/source/recipe/operation/request digest before it decides whether to repeat the upsert. For delete it counts the exact scoped source filter before deciding whether the tombstone still needs applying. The catalog's last-operation marker lets a new adapter reconcile the crash window after the generation CAS and before the operation result was committed. Unresolved or conflicting observed state fails closed and retains the durable alias operation row for exact recovery.

Per-source sequence rows and operation records currently have no owner GC/retention API. Production wiring must add a governed retention/bounds policy and evidence before long-lived operation is claimed disk-bounded. SQLite rows track durable logical state, not Qdrant byte growth or reclaimed physical bytes.

Search Hub now has an owner-bound semantic-store constructor and lifecycle startup attempts construction using its own provider-description source. Its current lifecycle does not register a full-recipe encoder, semantic admission issuer or peak estimator, so construction returns unavailable before any vector call. No Qdrant endpoint, model, index or collection was contacted for this source work.

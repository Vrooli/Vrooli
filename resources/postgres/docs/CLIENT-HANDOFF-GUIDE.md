# Client Handoff Guide — Retired

This guide described a retired client deployment model and shell workflow. Those
instructions do not apply to the current native managed-service PostgreSQL
resource and must not be used to start, package, or modify its database.

For current local resource lifecycle and connection guidance, use the
[PostgreSQL README](../README.md), [operations guide](OPERATIONS.md), and
[current requirements](../PRD.md). Customer deployment and packaging must be
planned through the current deployment-coordination workflow and the target
scenario's deployment documentation; this resource guide does not define that
process.

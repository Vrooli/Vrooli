# Stable Audio 3 Medium

Maintained local CUDA music resource. Two independent owner compositions matched
the declared artifact digest. The complete wheel-only `requirements.lock` was
resolved through Scenario Dependency Analyzer, including the official FlashAttention
wheel and unyanked Transformers5.10.4 patch. All12 model/support/notice files and
the public source archive are pinned. Native model loading and audio quality remain
separate qualification gates; a matching runtime tree does not establish either.

The pilot supports two separately admitted 48-second instrumental requests. It
does not establish better music, guarantee no vocals, or insert takes into Music's
durable jobs/pools. Existing `music-tools delivery arrange` owns matched excerpts.

See [API](docs/API.md) and [operations](docs/OPERATIONS.md). Model weights use
Stability Community and Gemma terms, not the source repository's MIT license.
